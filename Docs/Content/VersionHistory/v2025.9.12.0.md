Changes made in this release:


> [!IMPORTANT]
> As of this release, only Visual Studio 2022 and later are supported.  Support for Visual Studio
> 2019 has been dropped.  I do not use the older versions anymore, it will allow me to simplify the extension
> projects and keep the package references more up to date without the risk of breaking the build, and implement
> future features without regard to maintaining backward compatibility with the older versions.
> 
>

- Enabled installation on ARM64 PCs.
- Enabled installation in Visual Studio 2026.
